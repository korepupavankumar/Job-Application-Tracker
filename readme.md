# Job Application Tracker

## Problem Statement

Managing multiple job applications manually can be difficult. Job seekers may apply to different companies and positions and need to track their application status.

The Job Application Tracker is a Python application that helps users store, manage, search, filter, update, and track job applications.

## Objective

The objective of this project is to develop a simple Python application for managing job applications and tracking their current status.

The project also demonstrates Python programming concepts such as functions, object-oriented programming, lists, dictionaries, loops, conditional statements, exception handling, validation, file handling, JSON, searching, filtering, and data persistence.

## Features

- Add a new job application
- View all job applications
- Search applications by company or role
- Filter applications by status
- Update application status
- Delete an application
- View application statistics
- Validate application ID
- Validate dates
- Validate application status
- Save application data using JSON
- Load saved data when the program starts

## Technologies Used

- Python
- JSON
- Python Standard Library
- Object-Oriented Programming
- VS Code
